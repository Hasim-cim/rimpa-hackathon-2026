# Idea book

`idea-book.html` is the source of the shared page at https://claude.ai/artifact/7LMihfT937HfgTDYbCAjSB
(private until shared from the page's Share menu). Open the file in a browser to read it offline.

Six chapters: citation check, evidence weight, record passport, model recall, record-of-issue check,
policy studio, then "What we build". Ratings and build times are estimates 💭; all mockup data is invented.

To change it: edit the HTML here, then republish to the same artifact URL from a Claude Code chat
("republish docs/idea-book/idea-book.html to the idea book artifact").
