# 💡 Ideas board

Each of us adds ideas, then we score them together on **Sunday night**. We pick **one idea plus one fallback** before Monday 08:30.

## How to score

Score each idea **1–5** on each column. The last two columns are ours, not the judges'. They're the filters that sank or carried past entries.

| Column | Asks |
|---|---|
| **Idea** | Is it creative? Would the judges have seen it before? |
| **Fit** | Does it solve a real problem for an **organisation and its information manager**? |
| **Function** | Could it work and scale in the real world? |
| **Pitch** | Can we make it land in 5 minutes with one demo moment? |
| **IM core** | Does it put a real records act (capture, metadata, appraisal, keep or destroy) at its centre? |
| **8-hour build** | Can we show something working by Monday 3 pm? |

Any idea scoring **≤ 2 on IM core** is a generic AI tool. Rework it or drop it.
